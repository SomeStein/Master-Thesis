
\chapter{Invariant-Tree Algorithm}
\label{ch:hybridApproach}

This chapter gives a detailed account of the tree-flavoured invariant-polytope algorithm of \citet{MejstrikReif2025HybridApproachJSR}, called the \emph{invariant-tree algorithm} here. It states the vertex-wise termination certificate explicitly and connects that certificate to the toolbox implementation used in Chapter~\ref{ch:numericalTesting}.

\section{Overview}
\subsection{Combination Strategies}
\label{sec:hybridStrategies}
At its core, the invariant-polytope algorithm constructs a polytope norm adapted to the matrix family, while the finite-tree algorithm controls growth through product decompositions. This naturally suggests combining both algorithms.

One option is modular: first run the invariant-polytope algorithm for several iterations, then use the resulting norm inside the finite-tree phase. A second option is concurrent: update norm information and tree-decomposition information in each iteration. Following \citep{MejstrikReif2025HybridApproachJSR}, we use the concurrent variant.

\subsection{Problem Formulation}
\label{sec:hybridProblemFormulation}
After preprocessing from Section~\ref{sec:introPreprocessing}, we obtain a scaled family $\tilde{\mathcal{A}}$. From the chosen candidate and the three-member inequality \eqref{eq:three_member}, we already know $\JSR(\tilde{\mathcal{A}}) \geq 1$. Hence proving $\JSR(\tilde{\mathcal{A}}) \leq 1$ is sufficient.

To do this, we show that there exist a polynomial $p$ and a norm $\lVert \cdot \rVert$ such that, similarly to Chapter~\ref{ch:finiteTree}, every product can be bounded polynomially in its length:
\[
\lVert P \rVert \leq p(k) \quad \text{for all } P \in \tilde{\mathcal{A}}^k, \ k \in \N.
\]
The polynomial bound is obtained by decomposing each multi-index into finitely many parts arising from $1$-$v$-bounded test trees, plus one residual part controlled by finite-tree arguments.

\section{Algorithmic Formulation}
\label{sec:hybridAlgorithm}
The hybrid algorithm uses a vertex-wise version of the $1$-boundedness concept from Chapter~\ref{ch:finiteTree}.

\begin{definition}
\label{def:oneVBoundedTree}
Let $v \in \R^d$ and let $\lVert \cdot \rVert$ be a vector norm on $\R^d$.
An $\AG$-tree $T$ is called \emph{$1$-$v$-bounded} with respect to $\lVert \cdot \rVert$ if
\[
\sup_{L \in \mathcal{L}(T)} \lVert Lv \rVert \leq 1.
\]
If
\[
\sup_{L \in \mathcal{L}(T)} \lVert Lv \rVert < 1,
\]
then $T$ is called \emph{strictly $1$-$v$-bounded}.
\end{definition}

The algorithm starts, as in the invariant-polytope method, from a set $V_0$ of starting vertices.
Each vertex set $V_r$ defines a vector polytope norm $\lVert \cdot \rVert _{V_r}$.
At iteration $r$, for every vertex $v \in V_r$, we build a test $\AG$-tree $T_v$.
If an image $Lv$ lies outside the current polytope, it is added as a new vertex candidate.
If all test-tree leafages in one iteration are $1$-$v$-bounded with respect to the current polytope norm, the algorithm terminates.

\begin{algorithm}
  \caption{Invariant-tree algorithm}
  \label{alg:hybridApproach}
  \begin{algorithmic}
      \State \Input{$\mathcal{A}$ (set of matrices), $\mathcal{G}$ (set of generators), $V$ (set of starting vertices)}
      \State $V_{\text{new}} \gets V$
      \While {$V_{\text{new}} \ne \emptyset$}
          \State $V_{\text{rem}} \gets V_{\text{new}}$
          \State $V_{\text{new}} \gets \emptyset$
          \For {$v \in V_{\text{rem}}$}
              \State Choose a valid $\AG$-tree $\mathbf{T}$ as discussed in Section~\ref{sec:hybridImplementation}
              \State $\mathcal{W} \gets \{Lv : L \in \mathcal{L}(\mathbf{T}) \text{ and } \lVert Lv \rVert _{\text{co}_{\text{s}}(V)} > 1\}$
              \If {$\mathcal{W} \ne \emptyset$}
                  \State $V \xleftarrow{\cup} \mathcal{W}$
                  \State $V_{\text{new}} \xleftarrow{\cup} \mathcal{W}$
              \EndIf  
          \EndFor
      \EndWhile 
  \end{algorithmic}
\end{algorithm}

\section{Termination Theory}
\label{sec:hybridTerminationResults}

\citet[Theorem 2.7]{MejstrikReif2025HybridApproachJSR} prove the upper bound when one $V$-closed tree works for every vertex. Their Algorithm 3.1 allows a tree to be chosen separately at each vertex. The following theorem makes this vertex-wise implication explicit. Its proof is an independently written extension of the common-tree argument, using the cited prefix--leaf decomposition.

\begin{theorem}[Vertex-wise tree certificate]
  \label{thm:hybridTermination}
  Suppose that Algorithm~\ref{alg:hybridApproach} terminates with a finite set $V$ spanning $\R^d$. Assume that each selected $\AG$-tree is valid, its generators have spectral radius at most $1$, and it is $1$-$v$-bounded for its associated vertex $v\in V$ in the final polytope norm. Then $\JSR(\mathcal{A})\le 1$.
\end{theorem}

This is a correctness theorem for a finite stopping certificate. It does not guarantee that a particular heuristic for selecting trees will find such a certificate in finitely many iterations.

\subsection{Proof Strategy}
\label{subsec:hybridProofOutline}
We work in the norm of the final vertex set $V$. With one common tree, closure at every vertex bounds each leaf set in operator norm, as in the cited theorem. Different trees need not give that common operator-norm bound. Instead, an arbitrary product either lies in a node of the tree selected for its starting vertex or has a nonempty leaf suffix. In the latter case, leaf closure replaces the suffix image by a convex combination of vertices and leaves a shorter product. Induction then gives one polynomial bound for all products.

\subsection{Auxiliary Termination Results}

The next lemma is the vertex-wise form of the tree bound. Its proof follows the prefix--leaf decomposition of \citet{MoellerReif2014TreeBasedJSR} and the hybrid closure condition of \citet{MejstrikReif2025HybridApproachJSR}.

\begin{lemma}
  \label{lem:hybridArbitraryProductBound}
  Under the hypotheses of Theorem~\ref{thm:hybridTermination}, there is a monotone polynomial $p$ such that
  \[
    \lVert A_Iv\rVert_V\le p(k)
    \quad\text{for every }v\in V,\ I\in\mathcal I^k,\ k\in\N_0.
  \]
\end{lemma}

\begin{proof}
For each vertex $v$, Lemma~\ref{lem:finitePolynomialBound} bounds all products encoded by nodes of $T_v$ by a monotone polynomial. There are finitely many vertices and trees. Hence we can choose one monotone polynomial $p$, with $p(0)\ge1$, that bounds the operator norms of all products encoded by any of their nodes.

We prove the assertion by induction on the product length $k$. At length zero it follows from $\lVert v\rVert_V\le1$. Let $I$ have length $k>0$ and assume the assertion for shorter lengths. If $A_I$ is encoded by a node of $T_v$, the choice of $p$ gives $\lVert A_Iv\rVert_V\le p(k)$.

Otherwise the prefix--leaf decomposition for the valid tree $T_v$ writes $A_I=A_JP$ for some matrix $P$ in an uncovered leaf set $L$, where $|J|<k$. Since $T_v$ is $1$-$v$-bounded, $Pv$ belongs to $\mathrm{co}_{\mathrm{s}}(V)$. Thus there are coefficients $c_w$ such that
\[
  Pv=\sum_{w\in V}c_ww,\qquad
  \sum_{w\in V}|c_w|\le1.
\]
The induction hypothesis and monotonicity of $p$ now give
\[
  \lVert A_Iv\rVert_V
  \le\sum_{w\in V}|c_w|\,\lVert A_Jw\rVert_V
  \le p(|J|)\sum_{w\in V}|c_w|
  \le p(k).
\]
This proves the claim for every vertex and every product of length $k$.
\end{proof}

\subsection{Main Termination Result}

\begin{proof}[Proof of Theorem~\ref{thm:hybridTermination}]
Because $V$ spans $\R^d$, $\mathrm{co}_{\mathrm{s}}(V)$ is the unit ball of a norm. Any vector $x$ in that unit ball admits a representation $x=\sum_{v\in V}c_vv$ with $\sum_{v\in V}|c_v|\le1$. Lemma~\ref{lem:hybridArbitraryProductBound} therefore implies
\[
  \lVert A_Ix\rVert_V
  \le\sum_{v\in V}|c_v|\,\lVert A_Iv\rVert_V
  \le p(k)
  \quad\text{for every }I\in\mathcal I^k.
\]
Thus every product of length $k$ has induced operator norm at most $p(k)$. Taking $k$-th roots yields
\[
  \JSR(\mathcal A)
  \le\lim_{k\to\infty}p(k)^{1/k}=1.
\]
If the scaled family contains a candidate product with averaged spectral radius $1$, the reverse inequality follows from the three-member inequality, and the candidate is spectrum maximizing.
\end{proof}

\begin{corollary}
  If each chosen tree consists of the root and the $n$ one-letter positive leaves, then Algorithm~\ref{alg:hybridApproach} reduces to the invariant-polytope algorithm~\ref{alg:invariantPolytope}. Hence, the invariant-tree algorithm generalizes the invariant-polytope algorithm.
\end{corollary}

\begin{corollary}
  Assume Algorithm~\ref{alg:hybridApproach} terminates and all test trees coincide, i.e. $T_v=T$ for all $v\in V$. Then the product bound can be derived via a single prefix-leaf decomposition (PL decomposition) in matrix norm, as in Theorem~\ref{thm:finiteTreeTermination}, without vertex-wise recursive decompositions.

  More precisely, if
  \[
  A_I=A_{I_r}\cdots A_{I_1}
  \]
  is the PL decomposition induced by $T$, then
  \[
  \lVert A_I\rVert_{\mathrm{co}_{\mathrm{s}}(V)}
  \le
  \lVert A_{I_r}\rVert_{\mathrm{co}_{\mathrm{s}}(V)}
  \prod_{j=1}^{r-1}\lVert A_{I_j}\rVert_{\mathrm{co}_{\mathrm{s}}(V)}
  \le
  \lVert A_{I_r}\rVert_{\mathrm{co}_{\mathrm{s}}(V)}
  \le p(k),
  \]
  where $p$ is the polynomial from Lemma~\ref{lem:finitePolynomialBound}.
\end{corollary}

\begin{definition}
\label{def:hybridMinimalTree}
  An $\AG\text{-tree}$ with one generator branch at the root, one path from the root to the covered node, and all branches required to satisfy Definition~\ref{def:agTree}, is called a \emph{minimal tree}. This tree depends only on $\mathcal{A}$ and the chosen generator $G$. It is denoted by $T_{\AG}$ and, when $\mathcal{A}$ is clear from context, shortened to $T_\mathcal{G}$.
\end{definition}

In principle, the invariant-tree algorithm allows a different test tree for each vertex $v \in V$. More precisely, both the test tree and the corresponding bounding tree can be chosen independently for each vertex, as long as they satisfy the $\AG\text{-tree}$ conditions from Definition~\ref{def:agTree}.

The implementation constructs a minimal tree by default, but it also accepts manually supplied leaf words. For the main numerical example, two generator trees are supplied and a vertex may close under either one. Their admissibility is checked from the tree structure in Section~\ref{sec:numericsPrimaryTree}; the toolbox does not validate user-supplied words automatically. A larger tree may require more leaf-norm checks, but can establish closure when the minimal tree cannot.

Generator branches encode families such as $\{G^r:r\in\N_0\}$. The tested toolbox revision requires diagonalizable generator matrices with periodic leading eigenvalues. It splits each image into a periodic leading part and a decaying remainder, bounds the latter using norm equivalence and the stable eigenvalues, and tests the finitely many initial powers left by that bound. This is a restricted implementation of the general verification strategy in \citet[Section 3.3]{MejstrikReif2025HybridApproachJSR}; it does not use a pseudo-spectral-radius estimate in the active path.

The practical implementation also uses a maximal iteration counter $r_{\max}$. If no certificate is found before reaching $r_{\max}$, the algorithm stops and returns an approximation interval for $\JSR(\mathcal{A})$ via the three-member inequality:
\[
\underline{\rho}\ \le\ \JSR(\mathcal{A})\ \le\ \overline{\rho}.
\]
In practice, these bounds can already be accurate even when full termination is not achieved.

Finally, candidate handling from the pure invariant-polytope algorithm is still used in the invariant-tree setting. In particular, candidate rejection and candidate updates can be applied before or during invariant-tree iterations to improve robustness.

The output polytope need not be invariant under every matrix in $\mathcal A$: the certificate bounds leaf products at individual vertices. A strict check evaluates periodic limits, a bound for the stable part, and enough initial powers to cover the remaining range. Its cost depends on the generator spectrum, leaf words, and polytope-norm solves. Chapter~\ref{ch:numericalTesting} measures this cost for the tested families; the termination proof does not give a polynomial worst-case complexity bound.
